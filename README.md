# kalkulator-sederhana
Kalkulator sederhana dengan Python. 

Ini sebagai lahan praktekku cara menggunakan fungsi

Aku mulai dengan aritmatika terlebih dahulu disertai dengan kuis sederhana.


Ada kuis penjumlahan dengan 1-4 digit. 

Buka terminal kemudian masuk ke folder "kalkulator-sederhana".
```bash
cd kalkulator-sederhana
```
Kemudian buka modul/file python "kalku.py"
```bash
python3 kalku.py
```

Nanti muncul intruksi apa saja yang harus diinput
